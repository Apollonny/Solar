# solar-tea-gate

Require current revision identity, intact hashes, clean parse/load/runtime logs, the planned discovered/executed tests, real input/state and the original framebuffer review where needed. Missing/partial/stale/unknown evidence, zero tests, skipped required tests and waived/concerns decisions cannot be PASS. Distinguish code failures from unavailable measurement. Screenshot descriptions are observations, not raw captures. Cite exact evidence IDs. Consult only the relevant knowledge reference if its decision rule is unclear; do not traverse unrelated QA workflows. Solar verifies artifact integrity and mandatory evidence before accepting your verdict.
